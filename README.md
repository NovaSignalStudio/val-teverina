# Val Teverina

Sito statico per GitHub Pages, con 42 pagine, 17 località collegate per regione, 6 proposte di esperienza e 3 itinerari. Mappa geografica di Lazio, Umbria e Tevere; taccuino con tappe riordinabili, salvataggio locale, condivisione e download.

Design fotografico ispirato alla struttura di Lasso Photo Co., adattato al brief Val Teverina.

Pubblicazione: branch main, cartella radice. Percorso: /val-teverina/.

Font ospitati sul sito. Fotografie autentiche dei luoghi; immagini illustrative per attività senza operatori ancora confermati.

Il modulo consente di preparare e scaricare una richiesta: il destinatario del progetto è ancora da configurare. Iscrizioni e prenotazioni non attive. Nessun pagamento.
