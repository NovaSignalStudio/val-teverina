NAVIGAZIONE / PRIVACY

I tuoi dati, con chiarezza.

Il tuo taccuino

Le località selezionate e le preferenze di viaggio vengono conservate nella memoria locale del tuo browser, sul dispositivo che usi. Puoi cancellarle con “Svuota il taccuino” nella pagina La tua giornata o eliminando i dati del sito dal browser. Non sono salvate nei nostri server.

Richieste di informazioni

Il modulo prepara una richiesta sul tuo dispositivo. Nome, email e messaggio non vengono inviati automaticamente dal sito e non vengono conservati nella memoria locale. Il download salva un file sul dispositivo; la copia del testo usa gli appunti solo quando lo richiedi.

Il recapito del progetto non è ancora attivo: puoi scaricare una bozza della richiesta, senza inviarla.

Condividere un percorso

Il link di condivisione contiene solo le tappe e le preferenze del viaggio, senza nome, email o messaggi. Chi riceve il link può vedere quel percorso.

Servizi utilizzati

Il sito è ospitato su GitHub Pages. GitHub tratta dati tecnici di navigazione secondo la propria informativa. Il sito non utilizza strumenti analitici o pubblicitari propri.

Informativa GitHub

Link esterni

Google Maps e le fonti esterne vengono aperti solo quando scegli i relativi collegamenti. Si applicano le condizioni del servizio che apri.

Newsletter e prenotazioni

Il sito non iscrive automaticamente a newsletter e non effettua prenotazioni o pagamenti.
